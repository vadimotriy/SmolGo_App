# 🗺️ SmolGo

Мобильное приложение-гид по Смоленску с квестами, викторинами и интерактивными маршрутами



### 📋 О проекте
**SmolGo** — это инновационное мобильное приложение для Android, разработанное для повышения туристической привлекательности города Смоленска. Приложение помогает туристам из регионов Российской Федерации и Республики Беларусь комфортно и увлекательно знакомиться с достопримечательностями через:

- Интерактивные маршруты — структурированные пешеходные экскурсии с привязкой к карте
- Квесты — сценарии вовлечения с заданиями у реальных достопримечательностей
- Викторины — проверка и расширение знаний об истории и культуре региона
- Достижения — система мотивации с наградами за активность
- Два языка — полная поддержка русского и белорусского языков


### 📱 Минимальные требования к устройству:

- Android 10 (API 29) и выше
- 2 ГБ ОЗУ (рекомендуется)
- Доступ к интернету для загрузки *дополительного* контента


### ✅ Результаты тестирования:

- Успешное прохождение нагрузочных тестов (100+ одновременных запросов)
- Решение проблемы с интернетом
- Положительные отзывы от группы реальных пользователей в Смоленске


### 🌐 Локализация
Приложение поддерживает два языка интерфейса:

- 🇷🇺 Русский
- 🇧🇾 Беларуская

*Переключение языка происходит автоматически в зависимости от настроек устройства или вручную в настройках приложения.*


### 📊 Результаты исследования ЦА
На основе анкетирования более 70 респондентов (РФ + РБ):

- 64% респондентов из РФ и 38% респодентов из РБ желают посетить Смоленск 
- Геймификация повышает вовлечённость и запоминаемость информации
- Существует запрос на интерактивный образовательный контент


### 🎯 Запланированные улучшения:

- WEB-версия — планирование поездки с компьютера
- Расширение контента — новые маршруты, квесты, исторические факты
- Социальные механики — лидерборды, соревнования с друзьями
- Партнёрская программа — купоны от кафе, музеев, магазинов
- Мультиязычность — поддержка английского и других языков
